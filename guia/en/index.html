What it is

One file, zero dependencies

The Cloudflare dashboard is great for looking things up and terrible for repeating them. This script does the same thing through the API, in a way you can version, review, and run again tomorrow.

📦 Python 3 standard library only

No pip install. Copy the cf-dns.py for any machine with Python 3, and it runs — a new server, container, freshly created VPS.

🔑 Token kept out of the code

The credential comes from the variable CLOUDFLARE_API_TOKEN or a .env pointed to by CF_ENV_FILE. No secrets live in the repository.

▲ Vercel shortcut

The subcommand vercel creates the CNAME and verification TXT records at once, with the proxy already turned off — that’s the detail that usually blocks verification.

How it works

Three API calls, in the right order

There’s no magic: the script talks to the Cloudflare API v4. What it adds is a safe sequence—look before you write.

Read the token→ Find the zone_id→ List what already exists→ Create / delete→ Check

Find the zone

GET /zones?name=<dominio> returns the zone_id. Every record hangs off this ID — it's always the first step.

Look before you write

GET /zones/<id>/dns_records?name=… shows what’s already there. This prevents you from discovering a conflict only after breaking the site.

Write

POST creates and DELETE /dns_records/<record_id> removes. The list prints the id of each record, which is what the delete consumes.

Prerequisites

A token and Python—that’s all

There’s no service to start, daemon, or database. The script is stateless: each run is a brief conversation with the API.

Python 3

Any 3.x version your distro provides. No external packages are imported.

# check
python3 --version

Cloudflare API Token

In the dashboard: My Profile → API Tokens → Create Token, template Edit zone DNS. Permission Zone → DNS → Edit in the zones you’re going to modify. The token is shown only once.

# keep outside of git
echo 'CLOUDFLARE_API_TOKEN=SEU_TOKEN' >> ~/.env
chmod 600 ~/.env

The domain in Cloudflare

The zone must already be in the account, and the token must be able to see it. If it can't, the script tells you instead of failing silently.

# smoke test
./cf-dns.py list inema.club
User guide · step by step

From clone to live record

Five steps. The fourth is the one you'll repeat every time.

1

Install on a new machine

The entire repository is the script plus the documentation. Copy the file wherever your $PATH reaches.

git clone https://github.com/inematds/cf-dns
install -m 755 cf-dns/cf-dns.py ~/bin/cf-dns.py
2

Point to the token

Two ways: an environment variable or a file .env indicated by CF_ENV_FILE. Without either, the script refuses and explains why.

# environment variable
export CLOUDFLARE_API_TOKEN=seu_token

# or pointing to a file
export CF_ENV_FILE=~/.env
3

Look before you make changes

Always. The list shows the type, name, value, proxy status, and the id for each record — and that’s how you find an A record occupying the host you planned to use.

./cf-dns.py list inema.club          # the entire zone
./cf-dns.py list inema.club dlp2     # just one name
4

Create the record

The name can be just the subdomain (rede) or the full domain. The default TTL is 60 seconds — good while something is being checked.

# A record pointing to an IP
./cf-dns.py add inema.club A rede 192.168.2.99

# CNAME with a longer TTL
./cf-dns.py add inema.club CNAME app destino.exemplo.com --ttl=300

# with the orange proxy enabled (only when it makes sense)
./cf-dns.py add inema.club A site 203.0.113.10 --proxied
5

Delete when needed

O delete uses the id that the list printed — not the name. That’s intentional: you need to see the record before removing it.

./cf-dns.py list   inema.club dlp2
./cf-dns.py delete inema.club 76d14e9482f4b03f9d05a3c643f6cca7
Examples

The two cases that come up every week

Real commands, taken from actual use on INEMA domains.

▲

New subdomain in Vercel

Vercel requires two things: a CNAME pointing to vercel-dns and a TXT record in _vercel proving that you own the domain. The subcommand vercel does both, with proxy turned off — verification won’t pass with the proxy turned on.

./cf-dns.py vercel inema.club dlp2 \
  820ed52053a39f8f.vercel-dns-017.com \
  vc-domain-verify=dlp2.inema.club,5bc6ac41fe34ada1f4f9

Multiple TXT records in _vercel coexist without issue — one per subdomain. Once Vercel turns green, you can remove that subdomain’s TXT record.

🏠

Internal name for a LAN IP

You can use public DNS pointing to a private IP — it resolves only for those on the network (or VPN). The proxy must be turned off: Cloudflare does not proxy private addresses.

./cf-dns.py add inema.club A rede 192.168.2.99
# -> rede.inema.club responds to 192.168.2.99 on the LAN
